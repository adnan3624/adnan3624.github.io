Marketing Attribution and Incrementality

Comparing first-touch, last-touch, linear and position-based attribution, and how incrementality testing differs.

All data on this page is synthetic and illustrative. It demonstrates the method; it is not client data and the figures are not results.

Business context

A team wants to know how much each channel contributes to conversions, and whether paid channels create sales or only claim them.

Problem statement

Different attribution rules give different channel credit. None of them proves a channel caused a sale.

Data sources

  • Session-level touchpoints with channel and timestamp (GA4 export)
  • Conversions from the order system

Data architecture

Touchpoints are joined to conversions within a lookback window to create one path per conversion, then credit is assigned by each model.

Technical implementation

SQL assigns credit: first touch 100% to the first channel, last touch 100% to the last, linear equal split, position-based 40/20/40 style splits. Results are compared side by side.

SQL methodology

-- linear credit (illustrative)
SELECT channel, SUM(1.0/path_len) AS linear_credit
FROM conversion_paths, UNNEST(touch_channels) AS channel
GROUP BY channel;

Analytical outputs

  • Channel credit table under four models
  • Rank-change view showing which channels depend on the model chosen

Key findings

  • In the synthetic data, upper-funnel channels gain credit under first-touch and linear, while branded search gains under last-touch.

Business recommendations

  • Use attribution to describe the journey, not to prove value.
  • Use geo or holdout experiments with a pre-set sample size, confidence interval and decision threshold to measure incrementality for the largest budget lines.

Limitations and assumptions

Modelled attribution is correlational. Incrementality requires a control group (geo holdout, conversion lift or randomised test) and measures the causal effect. These are separate methods and should not be reported as the same thing.
