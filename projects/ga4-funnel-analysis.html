GA4 and E-commerce Funnel Analysis

Session and funnel analysis from the GA4 BigQuery export to find conversion leakage and reconcile revenue.

All data on this page is synthetic and illustrative. It demonstrates the method; it is not client data and the figures are not results.

Business context

An online store sees traffic rise while conversion rate falls, and the GA4 interface does not explain where users drop.

Problem statement

The GA4 UI samples and thresholds data, sessions are hard to rebuild, and purchase revenue does not match the order system.

Data sources

  • GA4 BigQuery export (events_*)
  • Order system extract for revenue comparison

Data architecture

Raw events are flattened into a session table (user_pseudo_id + ga_session_id), then into a funnel table with one row per session and a flag for each step.

Technical implementation

Event parameters are unnested in SQL. Steps follow GA4 e-commerce events: view_item, add_to_cart, begin_checkout, purchase. Results are cut by device, channel and landing page.

SQL methodology

-- session funnel (illustrative)
WITH s AS (
 SELECT user_pseudo_id,
  (SELECT value.int_value FROM UNNEST(event_params) WHERE key='ga_session_id') AS sid,
  event_name
 FROM `project.analytics_XXXX.events_*`
 WHERE _TABLE_SUFFIX BETWEEN '20260101' AND '20260131')
SELECT COUNTIF(event_name='view_item') AS viewed,
  COUNT(DISTINCT IF(event_name='add_to_cart', CONCAT(user_pseudo_id,sid), NULL)) AS carted,
  COUNT(DISTINCT IF(event_name='purchase', CONCAT(user_pseudo_id,sid), NULL)) AS purchased
FROM s;

Analytical outputs

  • Step-to-step conversion and drop-off by segment
  • GA4 purchase revenue versus orders by day

Key findings

  • In this synthetic example, the largest drop is between cart and checkout on mobile.
  • Duplicate purchase events inflate GA4 revenue unless deduplicated by transaction_id.

Business recommendations

  • Fix event duplication first, then prioritise the largest segment drop-off for testing.
  • Track a daily GA4-to-orders ratio as a health check.

Limitations and assumptions

GA4 export excludes users who decline consent unless Consent Mode modelling is used, and modelled data is not in the export. Funnel steps depend on correct event implementation.
